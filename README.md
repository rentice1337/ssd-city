# SSD City

**3D-визуализатор и очиститель дискового пространства для Windows.**  
Превращает структуру дисков и папок в ночной детализированный 3D-мегаполис: размер папки задаёт высоту и силуэт небоскрёба, а удаление мусора отправляет файлы в Корзину Windows с кинематографичной сценой сноса.

## Возможности

- **Многопоточный сканер диска** — быстрый обход через `FindFirstFileExW` с живым ростом города прямо во время сканирования.
- **Категории и цветовая кодировка:**
  - `Мусор / Кэш` (`node_modules`, `Temp`, `Cache`, `.gradle`, `.venv`, логи и дампы)
  - `Игры / Медиа / Архивы`
  - `Разработка / SDK`
  - `Система` (защищено от случайного удаления)
- **Детализированный 3D-город (DirectX 11 + 4x MSAA + ACES):**
  - 5 архитектурных типов небоскрёбов с подиумами, козырьками, парапетами, HVAC, вертолётными площадками и маяками;
  - квартальная сетка с магистралями, зебрами, оптоволоконной подсветкой, фонарями, деревьями и трафиком;
  - ночное небо со звёздами, луной и силуэтом дальнего горизонта.
- **Режим «Топ мусора»** — отдельный район из 100 самых тяжёлых кэшей и временных папок.
- **Снос зданий** — безопасное перемещение в Корзину (`SHFileOperationW`) с подлётом лайнера, ударом, пожаром, ударной волной и прогрессивным обрушением башни.
- **HUD и навигация** — поиск и фильтры по категориям, стек веса категорий, выносные 3D-метки, плавная инерционная камера и орбитальный обзор.

## Управление

| Клавиша / Действие | Функция |
|---|---|
| `W A S D` / `Стрелки` | Полёт камеры (`Shift` — ускорение) |
| `E` / `Space`, `Q` / `Ctrl` | Подъём / спуск |
| `ПКМ` (удерживать) | Обзор мышью |
| `Колесо мыши` | Ускорение / зум по взгляду |
| `ЛКМ` | Выбрать здание |
| `2x ЛКМ` | Войти внутрь папки |
| `Backspace` | На уровень вверх |
| `Del` | Снести выбранный объект в Корзину |
| `O` | Режим орбитального обзора |
| `R` | Сброс камеры |

## Сборка (Windows)

Требования: Windows 10/11, CMake 3.20+, Visual Studio / MSVC (C++20), Windows SDK (DirectX 11).  
Dear ImGui `v1.91.5` подтягивается автоматически через `FetchContent`.

```powershell
cmake -B build -A x64
cmake --build build --config Release -- /m
.\build\Release\ssd_city.exe
```
